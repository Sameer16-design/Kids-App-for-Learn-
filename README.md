# 🎓 Kids Fun & Learn App

A mobile-friendly interactive learning Progressive Web App (PWA) designed for kids to learn alphabets, animals, and practice drawing.

🚀 **Live App Link:** [Open Kids Learning App](https://sameer16-design.github.io/Kids-App-for-Learn-/)

---

## ✨ Features
- 🦁 **Animals & Birds:** Interactive emoji cards with animal names.
- 🎨 **Coloring Studio:** Fully functional canvas painting tool with customizable brushes and color palette.
- 🔤 **Learn ABC:** Alphabet cards with corresponding words and icons.
- 📱 **PWA / Mobile Installable:** Works like a native mobile app without downloading from Play Store.

---

## 📲 How to Install on Phone
1. Open the [Live Demo](https://sameer16-design.github.io/Kids-App-for-Learn-/) in Google Chrome on your phone.
2. Tap the **3 dots (⋮)** in the top-right corner.
3. Select **"Add to Home screen"** or **"Install app"**.
